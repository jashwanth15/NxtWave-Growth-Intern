# NxtWave Working Growth Asset: AI Placement Diagnostic & Viral Ticket Engine

## Overview
This interactive web asset was engineered specifically for the **NxtWave Growth Intern Challenge: "Build Your First AI Project in 60 Minutes"** to acquire 500 final-year engineering student registrations within 7 days on a strict ₹2,000 budget.

### Why This Beats a Standard Landing Page
1. **Psychological Reframe (The Hook):** Engineering students have "banner blindness" toward webinars. Instead of pitching a passive session, this asset serves as an **Interactive AI Placement Gap Diagnostic**. It shows students their real ATS risk before presenting the workshop as the 60-minute solution.
2. **Personalized VIP Boarding Pass Generator:** Renders a downloadable, personalized ticket badge (HTML5 Canvas PNG export) with unique registration ID and 1-click `.ics` calendar file.
3. **Product-Led Viral Referral Engine:** Locks the "VIP AI Project Starter Vault" (GitHub Repo + ATS Resume Templates) behind a 3-batchmate referral gate with 1-click WhatsApp sharing.
4. **Internal Growth Ops Command Center:** Evaluators can toggle to the internal Growth Analytics view to see live conversion rates, CAC calculations (₹3.86/student), channel attribution, and 7-day registration velocity.

## How to Run & Preview

### Option 1: Direct Browser Launch (Easiest & Fastest)
Double-click `index.html` or open it directly in Google Chrome, Microsoft Edge, or Safari. Everything runs client-side with zero dependencies!

### Option 2: Run via Node.js
If you have Node installed:
```bash
node server.js
```
Then visit `http://localhost:3000` in your browser.
